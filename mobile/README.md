# Thư mục mobile cũ

Thư mục này là prototype React Native/Expo từ bước triển khai trước. **Không dùng thư mục này cho bài nộp hiện tại.**

Ứng dụng cần chạy trên nền tảng web là Flutter app tại `../flutter_app`. Cách chạy đúng:

```powershell
cd "F:\Phát triển ứng dụng di động đa nền tảng\user-management\flutter_app"
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:3000
```
